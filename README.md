# HoverTranslate

**A Windows desktop application for translating selected text.**

HoverTranslate is a Python-based desktop application built with PySide6. It is designed to make translating selected text easier by using a keyboard shortcut and mouse-hover interaction.

---

## العربية

### نبذة عن المشروع

**HoverTranslate** تطبيق مكتبي لنظام Windows، مكتوب بلغة Python ويستخدم PySide6 لبناء الواجهة الرسومية. يهدف إلى تسهيل ترجمة النصوص المحددة أثناء العمل على الكمبيوتر.

### الوظائف الحالية

- تفعيل التطبيق وإيقافه باستخدام المفتاح `F9`.
- اختيار اتجاه الترجمة بين العربية والروسية:
  - `ar-ru`: من العربية إلى الروسية.
  - `ru-ar`: من الروسية إلى العربية.
- محاولة التقاط النص المحدد عند تمرير مؤشر الفأرة فوقه لمدة ثانية تقريبًا.
- استخدام الحافظة لقراءة النص المحدد مع محاولة استعادة محتواها السابق.
- عرض نتيجة الترجمة في نافذة مرتبطة بموضع مؤشر الفأرة.

قد يعتمد عمل بعض الوظائف على التطبيق الذي يحتوي على النص المحدد وإعدادات النظام.

### التقنيات المستخدمة

- Python
- PySide6
- PyInstaller لإنشاء نسخة تنفيذية لنظام Windows
- مكتبات Python إضافية موضحة في `requirements.txt`

### تشغيل المشروع من المصدر

يتطلب المشروع بيئة Python مناسبة ونظام Windows.

1. استنسخ المستودع وافتح مجلد المشروع.
2. أنشئ بيئة افتراضية وفعّلها.
3. ثبّت المتطلبات.
4. شغّل التطبيق.

الأوامر في PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m hovertranslate.main
```

### إنشاء نسخة تنفيذية

بعد تثبيت المتطلبات وPyInstaller، نفّذ:

```powershell
python -m pip install pyinstaller
python -m PyInstaller --noconfirm --clean --name HoverTranslate --windowed --onedir --paths . .\hovertranslate\main.py
```

ستجد النسخة الناتجة داخل:

`dist\HoverTranslate\`

في وضع `--onedir`، احتفظ بمجلد التطبيق كاملًا؛ لا تنقل ملف EXE وحده.

### حالة المشروع

المشروع قيد التطوير والاختبار. قد تختلف النتائج حسب التطبيق المستخدم لتحديد النص وإعدادات النظام.

## Русский

### О проекте

**HoverTranslate** — настольное приложение для Windows, написанное на Python с использованием PySide6. Оно предназначено для упрощения перевода выделенного текста во время работы за компьютером.

### Текущие возможности

- Включение и выключение приложения клавишей `F9`.
- Выбор направления перевода между арабским и русским языками:
  - `ar-ru` — с арабского на русский.
  - `ru-ar` — с русского на арабский.
- Попытка получить выделенный текст при наведении курсора мыши примерно на одну секунду.
- Использование буфера обмена для получения выделенного текста с попыткой восстановления его предыдущего содержимого.
- Отображение результата перевода в окне, расположенном рядом с курсором мыши.

Работа некоторых функций может зависеть от приложения, в котором выделяется текст, и от настроек системы.

### Используемые технологии

- Python
- PySide6
- PyInstaller для создания исполняемой версии приложения под Windows
- Дополнительные библиотеки Python, перечисленные в `requirements.txt`

### Запуск из исходного кода

Для работы проекта необходима подходящая среда Python и операционная система Windows.

1. Клонируйте репозиторий и откройте каталог проекта.
2. Создайте и активируйте виртуальное окружение.
3. Установите зависимости.
4. Запустите приложение.

Команды для PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m hovertranslate.main
```

### Создание исполняемой версии

После установки зависимостей и PyInstaller выполните:

```powershell
python -m pip install pyinstaller
python -m PyInstaller --noconfirm --clean --name HoverTranslate --windowed --onedir --paths . .\hovertranslate\main.py
```

Готовая версия будет находиться в каталоге:

`dist\HoverTranslate\`

При использовании режима `--onedir` необходимо сохранять всю папку приложения, а не только EXE-файл.

### Статус проекта

Проект находится в разработке и тестировании. Результаты работы могут зависеть от приложения, в котором выделяется текст, и от настроек системы.
